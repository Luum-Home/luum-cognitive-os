## Decision
Introduce `cos sprint` as a first-class, harness-agnostic concept with four primitives: a declarative Sprint YAML spec, a durable JSON manifest (`.cognitive-os/sprints/<id>.json`) with a pending→running→{completed,failed,cancelled} state machine, five canonical events extending ADR-033's registry (`SprintStarted`, `SprintTaskLaunched`, `SprintTaskCompleted`, `SprintCancelled`, `SprintCompleted`), and a CLI (`cos sprint {run,status,list,cancel}`).

## Why
COS already had the plumbing — ADR-033's canonical event schema and ADR-034's live event streaming (`canonical-live.jsonl`) — but lacked the sprint itself as a durable, reproducible artifact. Without these primitives, batching agent tasks was a chat-only workflow with no persistence, no harness portability, and no way to reconstruct what ran after the session ended.

## Consequences
Positive: sprints become reproducible YAML→manifest→events artifacts; the same CLI drives Claude Code, OpenCode, and Aider identically; canonical events integrate for free with existing cost-dashboard, SLO probes, and watchdogs. Negative: manifests are a new write surface that must tolerate corruption (`list_manifests` already skips bad JSON); the MVP `launch.md` hand-off is a manual fallback that can drift from the real dispatch logic if the orchestrator reinvents dispatch elsewhere; the zero-dependency stdlib YAML fallback parser limits spec complexity for users without PyYAML. Key risk: manifest/live-event skew if the orchestrator fails to call `transition()` after emitting events — mitigated by a planned reconciliation pass.

## Status & current state
Status remains "Proposed" in frontmatter but substantial waves have shipped: MVP (YAML spec, manifest, 5 events, CLI, tests) shipped 2026-04-20; Wave 1 test aggregator (`lib/sprint_test_aggregator.py`, pytest/go/jest/vitest parsing, 13 passing unit tests, `scripts/sprint-test-summary.sh`) delivered 2026-04-21; dispatch wiring (`cos sprint run --dispatch` actually invoking agents via `bin/cos-agent spawn --json` and updating the manifest) delivered 2026-05-01, covered by `tests/integration/test_cos_sprint_cli.py`. Still deferred: `cos watch --sprint` TUI, `SprintTestSummary` canonical event emission, and the `squash` consolidated-commit strategy.
