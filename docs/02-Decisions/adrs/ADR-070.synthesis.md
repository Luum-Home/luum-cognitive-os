## Decision
Codify four enforcement patterns as the menu every new convention must pick from: (A) an audit test that walks artifacts read-only and asserts pattern compliance, including a meta-test proving the detector can actually fail if the violation is reintroduced; (B) a pre-commit linter for code-level invariants (explicit rule selection, e.g. `ruff F401,F811,F821,F841`, no magic defaults); (C) auto-execute the convention's harder branch so an "OR" ambiguity is replaced with "always do A; B is optional and additional," removing human discretion as the source of drift; (D) a live integration test (not mocks) for any claim that two systems actually work together, marked `requires_X` and skippable when the dependency is unavailable. Every claim that would fail silently if unimplemented MUST have the highest-tier test for its category (mock < audit < live integration).

## Why
The shared meta-pattern across all three bugs: "a convention is real only when a mechanism enforces it." Documentation alone drifts because nobody re-reads it when shipping; mock-based tests prove parser correctness but not that the real import/integration exists; ADR sections without a matching audit test become aspirational. The operator's own framing, quoted verbatim: "fix everything and ensure there are tests please, end to end" — tests, not prose. This ADR amends ADR-069 §5's ambiguous "engram observation OR new ADR" into a hard rule: every accepted decision MUST create a `decision/<topic_key>` engram observation, with a new ADR optional and additional.

## Consequences
Positive: convention drift becomes visible at PR time instead of incident time; mock-test false confidence is cured for cross-system claims; the cost of enforcement is paid once by the convention's author rather than N times by downstream consumers who rediscover the same drift. Negative: every new convention now requires roughly 2x the lines of code/test concentrated in CI-only artifacts; Pattern D (live integration tests) can introduce CI flakiness if the dependency is unstable, mitigated but not eliminated by `requires_X` skip markers; authors face a one-time onboarding cost to learn the four-pattern menu.
