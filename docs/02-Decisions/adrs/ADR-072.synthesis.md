## Decision
Codify eight canonical test lanes (unit, audit, contract, integration-isolated, integration-shared, behavior, hooks, e2e, chaos — note the ADR body table lists 9 rows including a chaos row appended later) in `.cognitive-os/test-lanes.yaml` as the single source of truth read by both Go (`cmd/cos-test`) and Python (`tests/conftest.py`); each lane carries a written parallel-safe/serial contract with a stated reason. Add an escalation ladder — `cos-test focused` (git-diff-derived, <30s) -> `cluster --lane <name>` (<2-5 min) -> `broad` (every lane in dependency order, <10 min) — with `cmd/cos-test` as the canonical entry point and `pytest-with-summary.sh`/`Makefile` demoted to a transport layer and a one-release-cycle deprecation shim respectively.

## Why
Audit (`tests/audit/`, pure file scans) and contract (`tests/contracts/`, one shared-state offender in `test_global_verify.py`) lanes were forced serial for safety reasons that no longer applied, costing roughly 40% extra wall time; new contributors had no way to tell whether a lane was serial due to hook-chain state, fixture conflicts, or historical inertia; and `audit` was registered only in conftest, not `pytest.ini`, so a standalone run under `--strict-markers` would fail marker validation. Renumbering note: this ADR's proposal/spec/design reserved the slot as "ADR-069," but ADR-069 landed as the research-first-protocol before this ADR was applied, so it was renumbered to ADR-072.

## Consequences
Positive: every lane classification now has a written, challengeable reason; audit+contracts unlock parallelization (~90s to ~55s at `-n 4` once the `test_global_verify.py` shared-state fix lands); contributors learn one command with three escalation modes; every `cos-test` run prints lane/worker-count/ETA up front. Negative: one new YAML artifact to maintain and keep in sync; new test directories must be classified into a lane or an audit test fails (intentional friction); a two-release-cycle window where the doc-contract regex accepts both `pytest-with-summary.sh` and `cos-test` invocations before tightening to `cos-test` only.

## Status & current state
Accepted 2026-04-29. `implementation_status: partial` — the ADR's own classification notes the escalation ladder work "has now blocked iteration speed for 5 days" at drafting time, and the migration plan spans 9 sequenced batches (prereq fixes, lane registry, auto-marker injection, the parallelization flip with a `COS_FORCE_SERIAL_LANES` kill switch, the new `cos-test focused/cluster/broad` CLI, Makefile deprecation warnings, and final hard removal next release cycle) — implying rollout was still in progress across batches at ADR acceptance time.
