## Decision
Adopt Option A: a single root `.cognitive-os/plans/` with typed subdirectories — `features/` (SDD change plans), `research/` (pre-decision research/audits), `architecture/` (cross-cutting, ADR-linked, long-lived), `roadmaps/` (multi-quarter, product-level), `archive/` (completed/superseded, excluded from active indexing). All non-archive subdirectories MUST be indexed by `hooks/session-startup-protocol.sh`. Every plan file MUST declare `related-adr: ADR-NNN` or `no-adr-required: true` + reason in front matter, making the ADR↔plan link machine-readable for duplication-detection auditing. Rejected Option B (split operational-vs-architectural across two roots) because it requires agents to correctly self-classify before writing — already proven unreliable — and needs two startup index patterns with sync risk instead of one.

## Why
The core problem is discoverability, not organization for its own sake: the orchestrator cannot discover a prior plan if the directory it lives in isn't in the startup index, and once duplication occurs it compounds (later agents cite the duplicate instead of the canonical source, creating a second divergence). A single glob-indexed root resolves the confirmed failure mode directly; physical proximity to ADRs (Option B's argument) doesn't help discoverability since startup indexing is path-based, not proximity-based.

## Consequences
Positive: one glob pattern instead of seven for startup indexing; new agents that default to `.cognitive-os/plans/` (their existing gravity) comply without needing to read the ADR; the `related-adr` field plus audit tooling gives a duplication backstop; archive semantics become explicit for the first time. Negative: one-time migration cost (6-10 files, cross-reference updates required); `docs/04-Concepts/architecture/plans/` becomes a deprecated location that will silently accumulate wrong-place files from tooling/prompts that hard-code the old path until updated; the audit test is a CI backstop only, not a prevention mechanism (an auto-relocate hook is proposed but not mandated).
