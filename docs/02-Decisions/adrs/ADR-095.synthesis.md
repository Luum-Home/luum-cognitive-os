## Decision
Detect recurring tool-call sequences (Bash, Edit, Read, Write, Agent, etc.) across sessions via a new `tool-sequences.jsonl` instrumentation stream and pure Python n-gram counting (no LLM, $0 cost). Only successful invocations count toward pattern frequency; Bash rows store a redacted command shape (family/hash/capped preview) rather than raw text. Binding defaults: min_length=3, min_occurrences=3, window_days=7, auto_promote_threshold=5. Matching patterns auto-draft a skill in `skills/experimental/<auto-name>/SKILL.md` (tier experimental); the `/synthesize-skill` operator skill is the only path to promote a draft — auto-promotion is never automatic.

## Why
Portable Hermes primitives (MIT-licensed, `tools/skills_tool.py` and the `_SKILL_REVIEW_PROMPT` template) informed the design, but Hermes's per-turn background-thread counter mechanism and its `~/.hermes/skills/` storage location were judged incompatible with COS's event/hook model and git-tracked `skills/` directory, so they were not ported verbatim. Option B (repeated ad-hoc tool sequences) was chosen over detecting popular existing-skill invocations (Option A, doesn't find novel patterns) or high-trust-score task completions (Option C, requires a structured completion log not yet captured).

## Consequences
- Positive: genuine self-reinforcement — the OS proposes skills from its own successful behavior without waiting for a user to notice the pattern; zero LLM cost; PostToolUse hook body executes in under 1ms, well inside the <30ms design budget.
- Negative: false positives from low thresholds or noisy patterns create skill bloat (mitigated by a 30-skill experimental cap and operator-gated promotion); n-gram-generated draft descriptions are mechanically low-quality (LLM enhancement deferred); detection lag up to 7 days after a pattern first emerges; macOS `date +%s` 1-second resolution makes hook-health duration_ms imprecise for very fast hooks.

## Status & current state
Accepted, implementation_status: partial. Implemented: `hooks/tool-sequence-capture.sh` (PostToolUse, all tools), `lib/skill_synthesizer.py` (find_recurring_sequences/propose_skill_draft/auto_promote_eligible), `hooks/skill-synthesis-scanner.sh` (Stop event, 30-min cooldown), `skills/synthesize-skill/SKILL.md`, `skills/experimental/` directory, 37 unit tests (22+15) passing. Deferred: full semantic deduplication against the 146-skill catalog (only hash-derived idempotent naming exists today); the skill router does not yet include `experimental/` in its priority logic, so operator promotion remains mandatory.
