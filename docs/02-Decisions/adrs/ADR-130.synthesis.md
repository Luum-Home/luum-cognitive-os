## Decision
Suspend all eleven GitHub Actions workflow YAML files by renaming them to `.disabled` (a filesystem rename, not `gh workflow disable`), preserving their content for later restoration. Originally scoped to only the three Claude-API-calling workflows (`claude-interactive.yml`, `claude-issue-triage.yml`, `claude-pr-review.yml`) plus `cross-platform.yml`, the scope was extended the same day to all eleven after confirming zero-spend is the goal until self-hosted/local CI exists.

## Why
Three workflows invoke the Anthropic Claude API on every PR/issue event with the least predictable minute consumption. The remaining eight (shellcheck, pytest, go quality, audit, test lanes, etc.) were initially kept because they produce real Linux+macOS+Docker matrix coverage. But the maintainer pushes to `main` ~50 times/day, so `ci.yml` and `test-lanes.yml` alone would burn the free-tier 2,000 min/month quota in about a week — after which every workflow fails with the same billing message this ADR exists to fix. Full suspension was judged the cleanest posture under "no payment available."

## Consequences
- Positive: GitHub Actions billing on Claude API workflows drops to zero; the maintainer can run equivalent analysis locally in a Claude Code session at no per-PR cost; the `.disabled` files remain in the repo as documentation and are recoverable via `mv *.disabled *.yml`.
- Negative: PRs no longer get automated Claude PR review comments (mitigated: single maintainer reviews by hand); issue triage automation goes manual; `@claude` mention responses stop during suspension.

## Status & current state
Accepted, implementation_status: implemented — all eleven `.disabled` files listed in `implementation_files` exist. Local-CI replacement (pre-push hook + launchd schedules + on-demand CLI) is specified in the companion ADR-131 and tracked as future work under engram topic `backlog/local-ci-migration`. Re-enabling any single workflow is a one-line rename plus commit, contingent on verifying branch-protection required-status-checks first.
