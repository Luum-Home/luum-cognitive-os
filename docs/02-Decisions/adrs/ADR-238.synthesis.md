## Decision
Track all 5 bugs found during the audit as a single consolidated ADR Bug Registry (severity, affected file, reproducer, proposed remediation, status per entry) rather than as separate ADRs or GitHub issues, deferring fixes to individual PRs that reference this ADR.

## Why
Five thematically-linked follow-up bugs from one audit pass fragment poorly across the ADR catalog if split into separate ADRs (rejected: ADR-237b..f numbering bloat). GitHub issues were rejected because this project uses ADRs, not the issue tracker, as the canonical decision record (ADR-088 provenance model) — Critical/HIGH severity findings belong in ADRs. Auto-fixing inline during discovery was rejected to keep the focused audit (genericizing consumer tokens/fixture names) separate from bug remediation, since landing fixes inline would smear scope and complicate review.

The concrete bugs: (1) `kpi-trigger.sh` produced malformed JSON from ad-hoc bash string concatenation on mock fixtures; (2) `rules/skill-invocation-mandatory.md` referenced `.cognitive-os/sessions/events.jsonl`, a path that doesn't exist on a fresh install, failing a rule-audit test; (3) `cos_concurrent_status.py`/`concurrent_agent_safety_status.py` leaked an SO-only `concurrent_write` JSON key into non-SO project output, breaking portability schema; (4) `post-agent-verify.sh` snapshot restore fell back to `git checkout HEAD --` (restoring "base blocked" state) instead of the pinned pre-launch state, because `plan_snapshot` only copied untracked files, not tracked-modified ones; (5) CRITICAL — the chaos test `test_global_verify_regression_catches.py` wrote a fake resolver directly into the live `lib/targeted_test_resolver.py` path instead of a tmpdir, silently corrupting production source on every test run.

## Consequences
All 5 bugs resolved by 2026-05-08 (branch `session/m3-medium-resolutions-v2`), each in its own commit referencing this ADR: Bug 5 (CRITICAL) closed the test-safety violation with a `VERIFY_RESOLVER_DIR`-based tmp_path injection plus a defense-in-depth byte-snapshot assertion guarding against regression; Bug 2 (HIGH) fixed the dangling path reference so a fresh clone passes the audit; Bugs 1/3/4 (MEDIUM) fixed JSON construction, schema leakage, and snapshot completeness respectively. Whole-project portability suite reported 165/165 PASS as of 2026-05-08.

## Status & current state
Resolved — all 5 bugs fixed, each with a cited commit hash (`d00a9255`, `44fa5ff7`, `f016843e`, `d628a6ed`, `e0d9ba75`) and passing reproducer command. A consolidated verification one-liner chains all 5 reproducers plus a line-count check on `lib/targeted_test_resolver.py` (must equal 149).
