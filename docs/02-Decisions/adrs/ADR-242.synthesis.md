## Decision
Ship `scripts/cos-filter-repo-wrap.sh` as the sole call site for `git filter-repo --execute` within the governed toolchain; `lib/history_sanitization.py:execute()` delegates entirely to it. The wrapper: (1) snapshots and restores every remote (URL + push URL) around the filter-repo call; (2) computes a SHA-256 idempotency guard over the rules-file contents, the canonical rewrite-affecting env subset, and current HEAD — if `.cognitive-os/runtime/last-filter-repo.json` already records that exact triple, it refuses to re-run unless `--force-re-run` is passed (and that override is logged); (3) always writes `.cognitive-os/runtime/recovery.json` (`pre_head`, `post_head`, `backup_mirror_path`, `rules_hash`, `timestamp`), backed by a `git clone --mirror` snapshot taken before any rewrite; (4) appends an audit entry to `stash-ops.jsonl` per ADR-117 conventions.

## Why
`git filter-repo` strips `origin` by design as a safety measure, but that intentional behavior collided with routine governed use, costing manual remote re-adds every single run. The more dangerous failure was non-idempotency: two parallel filter-repo runs against overlapping rule sets with mis-configured env vars produced different SHAs with no detection that the same logical operation was being reapplied with drift, forcing a manual recovery from a backup mirror. No machine-readable pre/post-SHA or rule-set-fingerprint artifact existed, so reconciliation depended on shell history alone.

## Consequences
Positive: `origin` survives every rewrite without operator intervention; a second run with identical inputs against the same HEAD is a clear no-op rather than a silent re-mutation; `recovery.json` plus the timestamped mirror make rollback a documented operation instead of forensics; `stash-ops.jsonl` correlation enables auditable history hygiene. Negative: backup mirrors consume disk and need a TTL reaping policy; the idempotency-guard file is one more `.cognitive-os/runtime/` artifact to clean at session end; `--force-re-run` exists and could be misused, though it is logged.

## Status & current state
Accepted, Slice A implemented: wrapper preserves remotes, refuses non-idempotent reruns, writes recovery artifacts, and `lib/history_sanitization.py` delegates to it. `tests/behavior/test_filter_repo_wrap.py` covers remote preservation, idempotency refusal, force-re-run override, and recovery-artifact shape.
