## Decision
Enforce `lib/`, `scripts/`, and `hooks/` as read-only for the duration of every chaos test via an autouse pytest fixture, `chaos_readonly_workspace`, in `tests/chaos/conftest.py`. Three implementation tiers ordered by portability: (1) default portable snapshot-and-revert — fingerprint (inode, sha256, size, mtime_ns) every file before the test, revert and loudly fail-name any changed file after; (2) opt-in Linux `chaos-strict` lane using `bwrap --ro-bind` (or `mount --bind -o ro`) for kernel-level `EROFS` on write; (3) macOS opt-in via `chmod -R u-w` over a copy-on-write clone. The offending test now injects its simulated regression into a fixture copy of the resolver, not the production module.

## Why
The mutating chaos test is "the worst class of test bug: a test that silently mutates the source tree" — it cannot be caught by ordinary review because the mutation only manifests during the test's own execution. Observed symptoms: a concurrent agent reading the same checkout saw an inconsistent module body (the same cross-session contamination class ADR-239 addresses at the worktree layer), and the very test meant to detect regression of the resolver was the module the chaos test destroyed — a contradiction invisible to CI. The ad-hoc ADR-238 follow-up fix (env-var injection) fixed one test but left the bug class reachable by construction.

## Consequences
- Positive: a chaos test that mutates a protected file now fails loudly at teardown naming the file and diff, and the file is restored before the next test; `chaos-strict` opt-in turns the failure into an immediate `EROFS`, the most diagnostic signal possible.
- Negative: snapshot-and-revert computes sha256 for every file under three directories on every chaos test (small cost here, would need scoping on very large trees); two execution modes (portable vs mount-based) must be kept in sync via the runbook; any chaos test legitimately needing to write under `lib/` (none identified) would need an explicit allow-list and tempdir overlay.

## Status & current state
Accepted — Slice A implemented. `tests/chaos/conftest.py` installs the fixture, restores mutations under the three protected directories, and tests cover restore/remove/ignore behavior plus the original global-verify regression path. Protection scope is fixed to `lib/`, `scripts/`, `hooks/` only in this slice.
