## Decision
Introduce a manifest-driven control-plane audit runner (`manifests/control-plane-audits.yaml` + `scripts/cos-control-plane-audit`) that executes declared read-only audits by lane (`hook-fast`, `hourly`, `pre-public`) and aggregates their JSON findings into one report. It is explicitly not a repair engine — auto-correction is gated to a narrow safe-class list (regenerable reports, cache garbage, missing generated indexes); everything else (branch switches, history rewrites, sensitive data, chaos test source mutation, false "tests pass" claims) is block-and-report only.

## Why
ADR-239 and successors define the right protection classes, but nothing ran them "precisely and repeatedly without hand-invoking every script." The reliability claim could not honestly rest on "agents will be more careful" — it needed an automatic control loop: `declarative contract → automatic detector → hook/scheduler/release gate → metrics → remediation queue → separate fix → regression-prevention test`. As of 2026-05-08, running `scripts/cos-control-plane-audit --lane hook-fast --json` produced a real `block` status (15 findings, 11 blockers, 4 warnings) — proof the loop was still open and the doctrine's honesty depended on surfacing that, not hiding it behind a false green.

## Consequences
Positive: ADR-239+ detectors run continuously without bespoke per-ADR glue; hooks and cron/launchd share the same audit lanes; a single report answers whether unresolved postmortem classes remain; stable finding codes support future remediation tooling. Negative: one more manifest to maintain; a noisy underlying audit makes its whole lane noisy; hook integration must stay disciplined about only using the fast lane in hot paths.

## Status & current state
Accepted, Slice A implemented. `hook-fast` runs via `hooks/control-plane-audit.sh` before Agent launch, commit/push/destructive git commands, and public report writes; `hourly` runs via `hooks/control-plane-audit-hourly.sh` on Stop/session-end with a 3600s cooldown; `pre-public --strict` is wired into `lib/release_freeze.py`'s `control_plane_pre_public` check. State/metrics/remediation persist to `.cognitive-os/reports/control-plane/latest.json`, `.cognitive-os/tasks/control-plane-remediation.jsonl`, `.cognitive-os/metrics/control-plane-audit.jsonl`, and a findings-state file. Still open: transactional release freeze (ADR-246 pending), generalized safe auto-correction, and broader ownership/worktree audit coverage beyond "partial."
