## Decision
A critical governance primitive is not behaviorally proven until it has a declared behavioral proof contract with at least one falsification probe, tracked in `manifests/primitive-behavior-contracts.yaml` and checked by the read-only `scripts/primitive-behavior-audit.py`. Per critical primitive, the manifest declares the ADR that owns the behavior, expected proof test files, minimum behavioral evidence required, and allowed-to-warn overfit smells. The audit checks for: (1) negative/falsification probes, (2) runtime execution of the real primitive/API, (3) fail-closed assertion (exit code/exception/`status: block`), (4) boundary evidence (bypasses, positive controls, preservation cases).

## Why
ADR-240 through ADR-248 moved COS toward a manifest-driven control plane, but left a deeper gap: weak tests like "file exists," "settings.json references it," "ADR says Implemented," or "a happy-path fixture passes" give false confidence without proving the primitive protects the operator under pressure — the exact failure class the operator named as test overfitting.

## Consequences
Positive: prevents false confidence from existence/wiring-only tests; makes "implemented" claims depend on behavioral proof, not prose; gives future primitives a repeatable proof contract before release readiness. Negative: static proof audit cannot guarantee full semantic coverage — it is a guardrail, not a substitute for manual adversarial review or chaos tests; manifest patterns need maintenance as tests are refactored.

## Status & current state
Accepted — Slice A implemented (critical contracts only; broader chaos/race hardening is explicitly deferred as escalation/future scope). Slice A covers five incident-derived primitives: branch switch blocker, pre-public sensitive data gate, history sanitization, release freeze, and hook registration/classification projection. The audit runs as part of the `hook-fast` control-plane lane. Implementation files: `manifests/primitive-behavior-contracts.yaml`, `scripts/primitive-behavior-audit.py`, `tests/unit/test_primitive_behavior_audit.py`.
