## Decision
Replace the Jaccard semantic fallback in the skill router with a multilingual embedding matcher backed by FastEmbed (MIT) using `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (Apache-2.0, ~220MB ONNX, 50+ languages, ~9ms warm CPU latency). All 196 skills now participate, scored on `routing_intents + description + summary_line`. Cosine similarity cutoff is 0.50 (env-overridable via `COS_SEMANTIC_THRESHOLD`), with scores linearly mapped to a `[0.55, 0.85]` confidence band so the regex layer (which fires at >=0.75 with priority) always wins on overlap. `COS_DISABLE_SEMANTIC_ROUTING=1` fully disables the fallback before any model load.

## Why
Pre-fix, the semantic layer silently no-opped because its dependency wasn't installed, and even if it had been, token-overlap (Jaccard) matching between a Spanish prompt and English skill descriptions is structurally near-zero — it cannot bridge languages. The concrete failing acceptance case (a Spanish-language capability question) returned no skill match at all pre-ADR; post-ADR it resolves to `/product-answer` at confidence > 0.6. The chosen library (FastEmbed direct) rather than the originally-recommended `aurelio-labs/semantic-router` was a build-vs-buy call: the live PyPI release (`0.0.3`) ships no `Route`/`RouteLayer` symbols and isn't importable on Python 3.14, so the ~30 lines of routing arithmetic were implemented directly instead of wrapping an unusable upstream package.

## Consequences
Positive: multilingual routing across EN/ES/PT/DE/FR/IT with precision >=0.8 on the held-out test set; catalog embeddings are disk-cached and keyed by a SHA over model+corpus so cold-start cost (200-500ms load + ~1.5s embed for 196 skills) is paid once per catalog change. Negative/risk: operators may forget `fastembed` is opt-in (mitigated — matcher logs a warning and degrades to `[]`, regex layer keeps working); if `aurelio-labs/semantic-router` later publishes a working `0.1.x` release, this module's public surface is designed to stay stable if adopted later.

## Status & current state
Accepted and implemented 2026-05-13. `lib/semantic_skill_matcher.py` was fully rewritten (no compat shim; public surface `SemanticSkillMatcher`, `SemanticMatch`, `load_skill_metadata`, `from_routing_table()`, `match()` preserved). The unused `llm_classify` helper was removed. `SKILL.md` `description` is now the source of truth for routing; the legacy `intent_examples` field is still ignored by the loader. Tier: core (affects default routing/observability/primitive-governance).
