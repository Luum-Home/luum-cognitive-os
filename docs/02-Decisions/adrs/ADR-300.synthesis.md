## Decision
Phase 1 (accepted): document the benchmark winner (`multilingual-e5-large`, MIT-adjacent per its own license, precision@1 0.897 vs MiniLM's 0.753) and expose a runtime swap via `COS_SEMANTIC_ROUTING_MODEL` env var, without changing the shipped default. Phase 2 (adopting e5-large as default with a recalibrated threshold) was explicitly attempted and REJECTED the same day after empirical exploration showed no single threshold value satisfies the current test contract.

## Why
Measured cosine distributions under e5-large showed greetings at 0.80, negative-context false positives at 0.84-0.86, and a true-positive Spanish screenshot-bug prompt at 0.906 — overlapping ranges that no threshold cleanly separates (a threshold high enough to filter negatives, 0.87, drops held-out precision to 0.53 by rejecting 8/17 legit prompts). Adopting e5-large as default would require three coordinated changes not ready in this slice: recalibrating the ADR-297 LLM tie-breaker trigger band (which never fires under e5-large's denser scores), pivoting negative-context tests to exercise the full pipeline instead of the matcher alone, and an operator decision on what the `confidence > 0.6` band means under a denser-score model.

## Consequences
- Positive: operators get a one-env-var path to the +14pt accuracy upgrade without waiting for Phase 2; the conservative default keeps existing test contracts and threshold calibration intact; the benchmark report becomes load-bearing evidence that future model-selection ADRs must cite per the ADR-298 contract.
- Negative: `bge-m3`, `Qwen3-Embedding-0.6B`, and `microsoft/harrier-oss-v1-270m` remain blocked because none are registered in FastEmbed's curated TextEmbedding list — adoption requires a future ONNX-direct adapter, tracked as an ADR-301 candidate.

## Status & current state
Accepted, implementation_status: implemented (Phase 1 only). `lib/semantic_skill_matcher.py` and `manifests/routing-benchmark-models.yaml` ship the swap mechanism and benchmark manifest; default model remains `paraphrase-multilingual-MiniLM-L12-v2`. Phase 2 (threshold recalibration + negative-context test refactor) is deferred to a future ADR when the team has bandwidth. One pre-existing unrelated test failure noted (`test_generic_router_negative_context_rejects_false_positive_cluster[/deep-research]`, present before this ADR).
