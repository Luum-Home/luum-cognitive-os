## What it is
Institutional memory of 5 core "wounds" (anti-patterns) plus 2 later incident addenda that emerged while building Cognitive OS, with red flags and prevention principles to avoid repeating them.

## Key mechanics
- **Wound 1 — Speed Without Review:** v0.1.0 shipped 60+ hooks/80+ skills/30+ libs in one commit; `rate-limit-protection.sh` had an undetected O(n) subprocess-spawn adding 30-90s/agent call for months. Prevention: hook benchmark in pre-commit, pattern detector flags >2x duration regression, one-concern-per-commit discipline.
- **Wound 2 — Aspirational Metadata:** `audience:` field added to 120 SKILL.md files with no reader code for 18+ days; audit found 353 aspirational primitives (84 hook SCOPE tags, 95 lib scope tags, 5/6 SKILL.md frontmatter fields, 8/10 hook config flags, 18 config sections all unread). Prevention: `detect_dead_metadata` pattern detector, rule "no metadata without consumer," bidirectional-implementation principle.
- **Wound 3 — False Coverage:** 342 test files "felt reassuring" but 67 were purely structural (`path.exists()`, frontmatter checks); mutation testing on rate_limiter.py showed only 34% kill rate. Prevention: CI mutation-score gate (cosmic-ray, `.github/workflows/test-quality.yml`), `scripts/check_test_quality.py` pre-commit blocker, rule that tests must execute code.
- **Wound 4 — Agent Amnesia:** sub-agents start with zero context; 3 sequential audits in one session reported false numbers (20 "ghost" hooks were symlinks; 13 "missing" libs, 11 actually existed; 69 "phantom" skills, only 3 real) because none knew "this project uses symlinks" — inflated overhead estimate 2.7x, missing-libs count 6.5x. Prevention: `subagent-context-injector.sh` injects `templates/agent-mandatory-rules.md`; `hooks/_lib/file_checker.sh` symlink-aware checks; `/audit-integrity` skill.
- **Wound 5 — Stateless Decisions:** 252 commits in 18 days, zero ADRs; context lost permanently for many decisions. Prevention: `hooks/adr-detector.sh` (PostToolUse on git commit, 8 weighted signals, threshold >=0.70 generates ADR draft, rate-limited to 3 drafts/session, human review required).
- **Meta-wound:** all five wounds share silent degradation as root cause; meta-prevention is measurable self-awareness (pattern detector at session start, mutation testing in CI, hook benchmarks in pre-commit, auto-ADR on every commit, mandatory sub-agent rule injection).
- **Red flags checklist:** >10 primitives in one commit; field/flag added without PR showing reader code; test name containing "_exists"/"_has_section"/"_is_valid_yaml"; agent report conflicting with prior audit; architectural change without ADR draft; hook added without pre-commit benchmark; >50ms mean validator duration increase unexplained; mutation score <40% on any lib file; commit message with "TODO: wire up later"; primitive >3 days since last verified-working state.
- **7 principles:** no metadata without consumer; tests must execute code; sub-agents must inherit rules; architectural changes generate ADRs; measure before trusting (mutation score/latency/kill rate); symlinks are first-class (never call something missing without `readlink -f`); silence is the enemy.
- **2026-05-02 addendum — Stash mutation without coordination:** an anonymous, uncoordinated `git stash` by a pre-agent-snapshot hook silently removed 59 modified files from a parallel agent's view, contributing to cascading false-done reports (5+ revert events); only discovered via manual adversarial review. New principle (ADR-117): every stash-mutating hook must be named (stable session suffix), apply-by-name (never `pop`), auditable (JSONL to `stash-ops.jsonl`), budget-bounded (max 5 unrestored/session), and lock-coordinated (`stash.lock`). New red flags: anonymous stash entries without `cos-`/session-ID prefix; unmatched push/apply/drop in `stash-ops.jsonl`; `git stash pop` in hook code; >=5 unmatched push/drop pairs for one session.
- **2026-05-02 addendum — False-Done Compounding:** a sub-agent claimed "3 DELETE hooks already archived" when files existed in both `docs/99-Archive/` and live `hooks/`, one still registered in settings.json, one archive a symlink; plan marked `[x]` and committed to main; concurrent stash leak (59 files) and 3 uncoordinated fixes committed by a parallel session; caught by manual adversarial review before session end (ADR-105, ADR-106). New wounds: "Presence != Removal Fallacy" (archive present is not proof original+refs are gone) and "Orchestrator TRUST_REPORT Blind Spot" (90+ trust score compatible with false claims when cited verification is adjacent, not inverse). New principles: verify both halves (bilateral proof for archive/delete/wire/register); orchestrator is final gate (independent inverse verification before commit); stashes unapplied >10 min must alarm; plan checkboxes need inline `(verified: <cmd>)` proof; adversarial review on the critical path for plan-closing commits.
