## What it is
Post-mortem of the Cognitive OS "growth crisis" (v0.1.0 2026-03-27 through stabilization 2026-04-15/16): three compounding failure patterns (aspirational logic, false test coverage, invisible performance debt) and the measurement systems built afterward to prevent recurrence.

## Key mechanics
- **Timeline:** Phase 1 Genesis (Mar 21-27): AGPL audit replaced Redis/MinIO with Valkey/SeaweedFS; commit `1a7e421` (v0.1.0, Mar 27) added 60+ hooks/80+ skills/30+ libs in one commit, birthing `rate-limit-protection.sh` (O(n) subprocess loop, undetected 19 days), `completion-gate.sh` (unconditional EXIT trap, 42s/session wasted), `dispatch-gate.sh` (9 sequential Python cold starts). Phase 2 Explosion (Mar 28-31): 38 commits/day peak; SCOPE tags introduced with no consumers; namespace safety fix for `rm -rf` risk on `.cognitive-os` symlinks. Phase 3 Growing Pains (Apr 8-11): 472 "behavioral" tests added (later found partly structural); `dispatch-gate.sh` doubled 86->270 lines in 2 hours; rules-to-hooks refactor (73->14 always-loaded rules); Stabilization Freeze declared (commit `f49731d`, ADR-017, Apr 11) but `feat:` commits continued. Phase 4 First Crisis (Apr 13): "contamination fix" `57ed5cf` removed 40 lib + 34 hook files without updating references, producing false audits (20 apparent ghost hooks, 13 apparent missing libs); WS6 scope tagging applied to 82 hooks + 137 libs read by zero code. Phase 5 Awareness (Apr 15): 5 parallel Opus agents found real hook overhead ~36.5s/session (vs first estimate ~97s, 2.7x inflated), 353 aspirational primitives, 67 structural test files, 252 commits/0 ADRs; only 3/13 "missing" libs and 3/69 "phantom" skills were real. Fixed 3 worst hooks: `rate-limit-protection.sh` 30-90s->50-100ms, `dispatch-gate.sh` 2.1s->300-400ms, `completion-gate.sh` saved 42s. Phase 6 Reconstruction (Apr 15-16): 22 ADRs written, cos-dispatch Phase 1+2 (10 Go packages), pattern detector, auto-ADR hook, mandatory sub-agent rule injection, 2-tier CATALOG-COMPACT, CI mutation-testing gate, 67 structural tests deleted, stabilization 80%->93%+.
- **Root causes:** surface (velocity over verification: 252 commits/18 days avg 14/day peak 38/day; AI-generated at scale, single-person project with no peer review); deeper (measurement vacuum — no benchmarks/mutation testing/pattern detector until this session; documentation debt — 0 ADRs across 252 commits; metadata-as-implementation — fields counted as "progress" with no consumer; test theater — 342 files, kill rate unmeasured); systemic (open-loop feedback: code->tests pass->commit->next feature, no signal on slowdown or unread fields).
- **Contributing factors:** optimism bias (edge cases found in prod not tests); tool choice hiding problems (`pytest --tb=no -q` hid the 34% kill rate); fragmented memory (plans in engram 2,348 obs, code in git, rules in CLAUDE.md, no single aspirational-vs-implemented source); premature abstraction (dispatcher/adapters rushed before core stability); agent amnesia (each audit rediscovered the same symlink confusion independently).
- **Measured impact before/after:** test files 342->274 (94% behavioral); hook overhead unmeasured->~20s/session (44% reduction verified); ADRs 0->22; aspirational primitives 353+->0 remaining; mutation score unmeasured->34% baseline (CI gate at 40%); agent amnesia guaranteed->prevented via SubagentStart injection. Net ~4,000 LOC shrink while adding capability. Stabilization commits: 44 in one session (15 docs, 10 fix, 13 feat, 3 perf, 3 clean, 1 test).
- **Prevention mechanisms mapped to root cause:** velocity->`hooks/adr-detector.sh` + pre-commit Gate 3f + CI `.github/workflows/test-quality.yml` (mutation kill rate <40% fails PR); measurement vacuum->`lib/pattern_detector.py` + `hooks/pattern-check.sh` (SessionStart) + `hooks/_lib/file_checker.sh` + cos-dispatch Phase 4 (in progress); documentation debt->`templates/agent-mandatory-rules.md` injection + `stabilization-roadmap.md` + `FROZEN-BACKLOG.md` + `LESSONS-LEARNED.md` + 22 ADRs; metadata-as-implementation->`detect_dead_metadata` + CI schema-addition rejection; test theater->`scripts/check_test_quality.py` (AST-based) + `.cosmic-ray.toml`; agent amnesia->`hooks/subagent-context-injector.sh` + `/audit-integrity` skill.
- **10 distilled lessons** (AI-scale generation needs AI-scale measurement; schema additions aren't progress without readers; tests are a liability until they kill mutants; sub-agents are stateless by design; silent degradation is the enemy; velocity without feedback loops = debt; symlinks require `readlink -f`; document decisions in the moment; the freeze is a feature not punishment; self-awareness is the moat).
- **6 forward commitments:** no feature PR without an ADR (draft OK) for architecture changes; no schema addition without reader code in the same PR; no test that doesn't call subprocess/import/invoke a function; pre-commit must always run (never `--no-verify`); weekly LESSONS-LEARNED review; monthly FROZEN-BACKLOG review.
