## What it is
Canonical Go interface definitions for every pluggable component in cos-dispatch: Validator (reused from klaudiush), Transformer (new), Provider (new), Pattern Detector (new), Auto-Generator (new), and predicate combinators.

## Key mechanics
- `Validator` (unchanged from klaudiush): `Name()`, `Validate(ctx, hookCtx) *Result`, `Category()` (CategoryCPU/IO/Git, Git serialized to avoid index lock). `Result{Passed, Message, Details, ShouldBlock, Reference{Code, URL}, FixHint}`.
- `Transformer` (new): mutates rather than allow/deny. `Phase()` is PhasePre or PhasePost; `Priority()` (lower runs earlier); `TransformPre`/`TransformPost`. `Pipeline` holds ordered pre/post registrations sorted by priority; `Register(t, predicate)` (nil predicate runs on all events); `RunPre`/`RunPost` execute in order, predicate-filtered, error-wrapped with transformer name.
- `Provider` (new): normalizes agent-specific JSON to canonical `hook.Context` and builds agent-specific responses. `Name()`, `Detect()`, `Parse(raw) (*hook.Context, error)`, `BuildResponse(...)`, `ConfigPaths(projectDir)`. `Registry` holds providers (Claude, Codex, Gemini, Cursor, Devin) with Claude as fallback; `Detect()` iterates until one matches. Detection via env vars: Claude Code CLAUDE_PROJECT_DIR/CLAUDE_SESSION_ID, Codex CODEX_PROJECT_DIR, Gemini CLI GEMINI_PROJECT_DIR/GEMINI_CWD, Cursor CURSOR_SESSION_ID (inferred from .cursor/), Devin DEVIN_SESSION_ID (cascade context).
- Pattern Detector (new): `PatternType` enum (RepeatedFailure, FalsePositive, MissingCoverage, PerfRegression, ErrorCluster, SequenceCorrelation). `ExecutionRecord` is the SQLite row shape (id, timestamp, session_id, event_type, tool_type, tool_input_hash, validator_name, result, duration_ms, error_code, error_message, context_hash). `Tracker` interface: Record/Flush/Close (non-blocking, buffered). `Detector` interface: Analyze(since, minConfidence), AnalyzeSession(sessionID, minConfidence).
- Auto-Generator (new): `ArtifactType` enum (Validator, Transformer, Plugin, Rule). `GeneratedArtifact{Name, ArtifactType, SourcePattern, Code, Language, ConfigSnippet, Confidence, GeneratedAt, AutoGenerated}`. `FeedbackDecision` enum (Enabled, Disabled, Modified, Deleted). `Generator` interface: Generate(patterns), ApplyFeedback(artifactName, decision).
- Predicate combinators (from klaudiush Registry): And/Or/Not; matchers EventIs, ToolTypeIs, CommandContains, FilePathMatches, FileExtensionIs, GitSubcommandIs, ProviderIs. `Registry.Register(validator, predicate)` / `FindValidators(ctx)`.

## Relations & where used
Consumed by cos-dispatch/README.md's pipeline (Provider Detector -> Transformer Pre/Post -> Validator Dispatch -> Pattern Tracker) and by adr-detection.md's `ADRTransformerAdapter` (implements Transformer, registered via And(EventIs(PostToolUse), ToolTypeIs(ToolBash), CommandContains("git commit"))).
