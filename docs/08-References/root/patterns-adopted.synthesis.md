## What it is

The consolidated cross-source pattern-adoption ledger for Cognitive OS: 32 patterns from 8 origins (SuperClaude, Sprut Agent Kit, ClaudeClaw JS, QuinotoSpec, Sazonia Archive/TAC, Anthropic Engineering, Hermes Agent, Pi Coding Agent), plus 3 "original COS patterns" not attributed to any external source.

## Key mechanics

- **From SuperClaude (MIT, 22K stars) — 6 patterns**: Confidence Check (`skills/confidence-check/SKILL.md`, 5-dimension pre-implementation readiness score, <60 requires clarification); Deep Research (`skills/deep-research/SKILL.md`, quick/standard/deep/exhaustive depth levels via `lib/web_crawler.py`); Self-Review 4-question checklist (`skills/self-review/SKILL.md`); Implementation Completeness / No-TODO rule (agent preamble + DoD checks); PDCA Mistake Template (maps into error-learning JSONL: planned/done/check/act -> task_description/error_output/error_type_classification/remediation_applied); Error Signature Matching via Jaccard similarity (`lib/error_matching.py`, 5-regex normalization, 0.7 threshold).
- **From Sprut Agent Kit (MIT) — 4 patterns**: Memory Decay (`lib/memory_decay.py`, type-specific decay rates — architecture 0.3%/day, bugfixes 2%/day, preferences 0.1%/day); Anti-Sycophancy (feeds `rules/trust-score.md` mandatory-uncertainty requirement and `rules/adversarial-review.md` zero-findings prohibition, implemented as structural evidence requirements rather than phrase-blocking); Skill Routing Table (`rules/model-routing.md`, `lib/model_router.py`, multi-provider cost-aware routing); Persistent Agent Pattern (`skills/persistent-agent/SKILL.md`, `data/` dir with identity YAML + event log JSONL + auto-fixation checklist, combined with the Engram sidecar pattern).
- **From ClaudeClaw JS (aravhawk) — 3 patterns**: SecretRef (`lib/secret_ref.py`, ported TS->Python, `env`/`file`/`literal` sources, `mask_secrets()`); Tool Group:Ref syntax (feeds `rules/agent-customization.md` and `rules/agent-identity.md`, `tools_allowed`/`tools_blocked` YAML lists, monotonic permission attenuation, trust levels 0-3); Structured Error Classifier (`lib/error_classifier.py`, categories build/test/lint/runtime/integration/configuration, feeds auto-repair dispatcher).
- **From QuinotoSpec — 3 patterns**: Contract Drift Detection (`tests/behavior/test_contract_drift.py`, part of sdd-verify); Proposal Conflict Detection (`tests/behavior/test_proposal_conflicts.py`, Engram-searched project-wide, blocking-vs-advisory severity); Sprint Contracts / verification lines (feeds `readiness-check` skill and `rules/acceptance-criteria.md`).
- **From Sazonia Archive (TAC course) — 5 patterns**: ClaudeExecutor (`lib/claude_executor.py`, programmatic CLI wrapper with Agent Bus integration); Batch Runner (`lib/batch_runner.py`, parallel task execution respecting resource governor limits); Resume from State (`lib/session_state.py`, `lib/sdd_resume.py`, Engram-integrated); Notifications (`lib/notifications.py`, Telegram/Slack/webhook, rate-limited); Issue-to-PR Pipeline (`lib/issue_pipeline.py`, SDD-integrated for complex issues).
- **From Anthropic Engineering — 3 patterns**: Generator-Evaluator Loop (sdd-apply/sdd-verify cycle, `rules/closed-loop-prompts.md`, max 3 retries, DAG state in Engram); Sprint Contracts / verification-before-implementation (readiness-check gate formalized in the SDD dependency graph); Skeptical Evaluator / Adversarial Review (`rules/adversarial-review.md`, mandatory >=1 finding, BLOCKER/CONCERN/SUGGESTION/QUESTION tiers).
- **Original COS patterns — 3**: Scored Skill Archive (`lib/skill_archive.py`, fitness tracking, rollback trigger at 20+ points below best known version); Staged Verification / fail-fast pipeline (`lib/staged_verification.py`, 7 stages from syntax (~$0, 0.1s) to cross-model verification (~$0.01, 30s), stops at first failure); Evolutionary Self-Improvement (archive-driven triggers: underperformance <60% success, trend degradation, rollback candidates — feeds `rules/self-improvement-protocol.md`, bounded by max-5-auto-improvements/test-gate/blocklist/cooldown).
- **From Hermes Agent (MIT, 9,431 LOC, 465 tests) — 4 patterns**, added as git submodule 2026-04-08: Memory Scanning mid-task (`lib/memory_scanner.py`, scoped by Engram prefix, budget-respecting); Injection Fencing (strengthens `hooks/content-policy.sh`/`hooks/aguara-scan.sh` boundary — "data vs instruction" framing for tool inputs, not a new hook); Skill Nudge via Background Review (`lib/feedback_detector.py`, scans recent `mem_save_prompt`-captured feedback, advisory nudges only); Hybrid Retrieval / holographic plugin (`lib/memory_retriever.py`, SQLite FTS5 keyword + vector, default 0.7/0.3 weighting, falls back to keyword-only without embeddings).
- **From Pi Coding Agent (MIT, 7 packages, 161 tests) — 4 patterns**, added as git submodule 2026-04-08: File Mutation Queue (`lib/file_mutation_queue.py`, Python/asyncio port of Pi's TS queue, session-scoped, priority + timeout, complements advisory locks in `session-concurrency.md`); Compaction Cut-Points (influences `hooks/pre-compaction-flush.sh` checkpoint placement and `rules/crash-recovery.md`; implemented as `# CUT-POINT` markers in long-running skills rather than loop-level markers, since Claude Code's hook architecture differs from Pi's loop); Structural Tests (agent-behavior-invariant tests, now enforced via `tests/unit/test_cos_test_quality_audit_scope.py` — explicitly noted that the old `tests/structural/` directory "is no longer a live surface"); Settings Override Per Environment (`--settings-override` YAML delta flag in the test harness, merged over `cognitive-os.yaml`, test-only).
