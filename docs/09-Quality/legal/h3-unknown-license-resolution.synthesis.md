## What it is
The H3 audit closing the residual provenance/clean-room gap: manual SPDX-license resolution for every component in `sbom.json` (CycloneDX 1.6, generated by syft 1.44.0) that syft left with a null/empty `licenses` field, resolved 2026-05-08.

## Key mechanics
- Scope: 186 raw UNKNOWN component records (157 unique by name+version), extracted via `jq '.components[] | select(.licenses == null or .licenses == [])' sbom.json`. Clarifies a prior-doc discrepancy: an earlier "14" figure in `docs/09-Quality/security/supply-chain.md` referred to the REVIEW bucket (LGPL `@img/sharp-libvips-*`), not this UNKNOWN bucket.
- Methodology: de-duplicate by (name, version); resolve canonical SPDX from upstream LICENSE/LICENSES/COPYING file (preferred), PyPI License field, GitHub license sidebar (cross-checked against the actual file), or the Go module's upstream repo; bucket per `rules/license-policy.md` into OK (MIT/BSD/Apache-2.0/ISC/MPL-2.0/PSF/Unlicense/CC0/FSL-1.1/0BSD), REVIEW (LGPL/GPL), BLOCKED (AGPL/SSPL/BUSL), or first-party (own artifacts, inherit repo LICENSE).
- Resolution breakdown by category: 8 first-party artifacts (own project files/go.mod/PyPI dist, all OK under FSL-1.1-MIT); 3 GitHub Actions (all MIT, OK); 90 PyPI packages (89 OK, 1 REVIEW — `chardet@7.4.3` LGPL-2.1-or-later, approved under the same dynamic-linkage/notice-retention rationale as the prior sharp/libvips REVIEW disposition, tracked for `THIRD_PARTY_NOTICES` aggregation under ADR-238); 60 Go modules (57 OK, 0 REVIEW, 0 BLOCKED).
- Final bucket counts: 186 raw UNKNOWN rows resolved to 185 OK + 1 REVIEW (`chardet`) + 0 BLOCKED. Project-wide combined with the prior `supply-chain.md` §3.2 baseline: OK 91->186, REVIEW 14->15, BLOCKED 0->0, UNKNOWN 100->0; total converges to 201 unique (name, version) tuples after collapsing own-project artifacts under one first-party row (vs. 205 pre-resolution with duplicate-purl entries counted separately).
- Operator decision: all 186 raw UNKNOWN rows (157 unique) accepted with 0 BLOCKED entries; H3 release gate clears. Recommends future SBOM regenerations prefer `cyclonedx-py environment` and `cyclonedx-gomod mod` (which embed SPDX directly) over the syft-only path used here, with the automation follow-up tracked under ADR-238.
- Explicitly documents that `sbom.json` is preserved verbatim as syft's literal output — this document, not a retro-edited SBOM, is the system-of-record for the human classification.
